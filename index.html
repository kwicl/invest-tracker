Configuration Google Sheets

Connectez l'application à un classeur Google Sheet en collant l'URL de votre application Web Google Apps Script ci-dessous.

Étapes de mise en place :
1. Allez dans Google Sheets de votre classeur > Extensions > Apps Script.
2. Remplacez le code par le script de synchronisation fourni dans le guide.
3. Cliquez sur Déployer > Nouveau déploiement.
4. Choisissez Application Web, puis configurez l'accès pour Tout le monde (Anyone).
5. Copiez et collez l'URL fournie par Google ci-dessus.
